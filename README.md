# 水溶液あて（suiyoeki-ate）

実験の結果（においがある・あわが出ている・蒸発させると白い物が残る など）を読んで、水溶液（塩酸・炭酸水・食塩水・石灰水・アンモニア水）を当てる1日5問の学習ゲーム。正解したら「何性？」（酸性・中性・アルカリ性）も選ぶ。小学6年理科「水溶液の性質」。

遊ぶ: <https://satou-aaaaa.github.io/suiyoeki-ate/>

- 中身は札幌市教育委員会の学習課題、岡山県・仙台市立作並小学校の学習指導案、福島県教育センターの資料で確かめたことだけです。
- 家で薬品をまぜたり、においをかいだりしないでください。気体の性質は「気体あて」で扱います。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。ただし結果画面で X・LINE の共有を押したときだけ、結果の共有文（正解の数など）がそのサイトに渡ります。
